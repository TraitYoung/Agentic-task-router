## 项目经历

### 1. specForge — AI 软件工程规格生成与代码审查系统

**独立全栈项目** | *2026年01月 - 至今*

**项目背景：**
面向 AI Coding 中"代码能生成但难以工程化落地"的问题，构建多 Agent 协同开发系统，支持从自然语言想法生成需求规格、开发计划、测试方案和 Cursor Prompt，同时支持逆向分析现有代码库，识别架构风险与质量问题。

**GitHub：** https://github.com/TraitYoung/specForge

**技术栈：** Python、FastAPI、Next.js 16、TypeScript、LangChain、Qwen、Pydantic v2、Redis、SSE、RAG

**主要工作：**

- 针对 AI 生成流程缺少工程闭环的问题，设计正向工程与逆向审查双模式流水线，覆盖需求发现、Sprint 规划、实现草案、测试方案、代码理解与质量分析，提升生成结果的工程可执行性。
- 针对 LLM 输出不稳定、上下文传递成本高的问题，基于 Pydantic v2 构建结构化输出模型，并在阶段间传递 JSON 摘要，降低解析失败和 Prompt 膨胀风险。
- 针对模型缺少真实项目上下文的问题，引入 RAG 检索增强，将代码库、README、接口文档和历史生成结果向量化索引，在分析与规划阶段动态召回相关内容，提升输出与项目实际结构的一致性。
- 针对多 Agent 串行执行延迟高的问题，使用 ThreadPoolExecutor 并行执行弱依赖任务，并结合步骤级 Trace 记录耗时与摘要，提升响应速度和流程可观测性。
- 基于 FastAPI + Next.js 16 完成端到端落地，支持 SSE 流式输出、Redis 会话缓存和 Cursor Prompt 导出，形成从想法输入到工程执行提示词生成的完整闭环。

### 2. 扩散模型医学影像生成与自动评估系统

**独立全栈项目** | *2026年02月 - 至今*

**项目背景：**
针对乳腺 X 光医学影像数据稀缺、生成质量难以客观量化的问题，构建基于 SD + LoRA 的高逼真度影像生成与自动评估闭环系统。

**GitHub：** https://github.com/TraitYoung/medi-diff

**技术栈：** Stable Diffusion、LoRA、Python、FastAPI、Gradio、Qwen-VL、DeepSeek

**主要工作：**

- 针对分块拼接伪影问题，设计全图单次 img2img 推理管线，以 LoRA（25MB）微调 SD1.5，单卡生成 2048px 高分辨率影像，从架构层面消除 seam banding。
- 针对人工评估不可规模化的问题，建立 16 维量化评估体系（形状、纹理、频域、伪影、灰度、解剖），以规则化打分替代主观审阅，支撑 60+ 轮超参迭代可复现、可对比。
- 针对评估指标与视觉质量存在偏差的问题，接入 Qwen-VL + DeepSeek 多模态模型进行视觉校验与自动调参建议，将 Agent/Workflow 编排思维落地到医学 AIGC 场景。
- 基于 FastAPI + Gradio 完成服务化部署，结构化存储实验参数与评估结果（JSON Schema），历史回溯与一键流水线执行。

**项目成果：**
- 单卡生成 2048px 影像 500+ 张，消除拼接伪影
- 自动化闭环 60+ 轮迭代锁定最优超参区间
- 全链路 AIGC 系统落地
